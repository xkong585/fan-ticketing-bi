# Tableau aggregate views

Open the packaged .twbx in Tableau Desktop. CSVs are embedded and contain official-source aggregates only, without Census participant records or credentials. The two audiences in the survey/sponsorship workbook are unrelated datasets, not linked customers. NCAA school/home and historical/all-games scopes remain distinct. Rates are one precomputed estimate per category; do not sum rates or average subgroup means to estimate an overall population. The HTML report contains full uncertainty, filters, model comparisons and limitations. Native rendering verification is recorded separately in evidence/presentation_qa.json.
