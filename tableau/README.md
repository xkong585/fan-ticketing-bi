# Tableau aggregate views

Open the packaged .twbx in Tableau Desktop. All data are synthetic aggregates; the CSVs are embedded. No credentials, external database, workbook fingerprint or real fan records are included. Numerical fields are additive counts/amounts unless explicitly labelled as rates. Do not sum per-group rates to form an overall rate; use the numerator and denominator exports in evidence. The separate HTML report provides brand/month/sponsor filtering and validated ratio calculations.
