# 项目阅读说明

本项目全部使用生成的合成数据，品牌和赞助商为虚构。没有真实球队授权、真实营收提升或实际问卷发放。

这是票务 BI 项目：20,000 名合成球迷、120 场活动、119,998 笔有效订单。展示以分为单位的财务核对、截至固定日期的分群、后续 90 天验证、SQL 物化报表性能，以及 Tableau/HTML 汇总报告。

运行 bash run_all.sh 生成数据、核对、测试和报告。reports/index.html 可以本地直接打开；tableau/ 下的 .twbx 可以在 Tableau 中打开。GitHub 网页不会执行 HTML，请下载仓库或报告后查看。工作簿仅嵌入汇总 CSV。简历可用表述见 resume_bullets.md；口径见 metric_dictionary.md。
